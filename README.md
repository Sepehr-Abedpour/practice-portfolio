# Practice Portfolio 

یک پورتفولیوی شخصی که با **HTML** و **CSS** ساخته شده. این پروژه برای تمرین ساخت چند صفحه‌ای، لینک‌دهی بین صفحات و استایل‌دهی با CSS طراحی شده است.

## مشاهده آنلاین

[مشاهده پورتفولیو](https://sepehr-abedpour.github.io/practice-portfolio/)

## صفحات پروژه

- **صفحه اصلی (`index.html`)** — معرفی، پروژه‌ها و مهارت‌ها
- **درباره من (`about.html`)** — اطلاعات بیشتر درباره من
- **تماس با من (`contact.html`)** — راه‌های ارتباطی

## پروژه‌های پایتون

این پورتفولیو به پروژه‌های پایتون من هم لینک داده:

- **TGJU Price Scraper** — وب اسکرپر قیمت طلا و دلار
- **School Management** — سیستم مدیریت مدرسه
- **Number Guessing Game** — بازی حدس عدد با پایتون

## تکنولوژی‌های استفاده‌شده

- HTML5
- CSS3
